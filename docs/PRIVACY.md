# 数据与隐私

描述默认源码行为，不替代运营者在微信公众平台提交的隐私指引。

| 数据 | 默认处理 | 是否上传 |
| --- | --- | --- |
| 课表、学期设置 | 本机解析，确认后保存 | 否 |
| 成绩留档 | 主动导入，确认后保存快照 | 否 |
| 取件信息 | 手动输入或主动粘贴，确认后保存提取字段 | 否；不保存原通知全文 |
| 剪贴板 | 点击复制入口时写入 URL | 不上传剪贴板内容 |
| 留言 / 联系方式 | 默认关闭；自行启用后主动提交到自己的云环境 | 仅启用并提交后 |
| 访问统计 | 默认关闭；启用后按标识摘要和北京时间日期去重 | 仅启用后 |

不自动读取短信、通知、通讯录、位置或教务密码；没有课表跨设备同步。清缓存、卸载或更换设备可能丢失记录，请保留原文件。

## 可选留言与统计

留言仅本人 / 作者可见，不是公开留言墙。选填联系方式随留言保存，作者处理时可查看。不要填写密码、验证码或证件。

去重使用 AppID 与 OPENID 的 SHA-256 摘要，保留日期 / 计数等数据；这是标识符处理，**不是完全匿名化保证**。不计 H5 / 开发者工具，统计失败不阻塞本地功能。运营者启用前需明确保留、删除和处理请求渠道。

当前 `COMMUNITY_READY = false`，云端接通未验证。页面存在不代表内容已送达，以明确成功结果为准。

## 外部服务与问题反馈

教务、图书馆、校园卡和外卖由原平台运营，登录、预约、订单、支付与数据政策由其负责。本项目不代理业务，也不使用个人登录票据作为公共入口。

Issue 优先使用自造样例；不要上传姓名、学号、成绩、真实取件信息、Cookie、Token、Ticket、session_key、AppSecret、私钥、设备配对文件或含认证信息的完整 URL。私密问题按 [SECURITY.md](../SECURITY.md) 联系作者。
